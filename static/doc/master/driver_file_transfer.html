File Transfer Driver

Serves a file or a directory tree with the FileType and FileDirectoryType Methods of OPC UA Part 20. Each driver owns one storage backend; the built-in backends serve local files and directories.

The driver needs UA_ENABLE_DRIVER_FILE_TRANSFER. The reduced and the full Namespace Zero contain the required types; with MINIMAL or NONE, load them before constructing a driver. Serving Files and Directories shows the setup.

Storage Backend

UA_FileTransferFileBackend serves one file, UA_FileTransferBackend a directory tree. Each driver needs a backend context of its own. The callbacks return OPC UA StatusCodes. Paths are UTF-8 and relative to the backend root, with ‘/’ as separator; the empty path is the root.

Every backend needs open, close, read, getPosition, setPosition and getInfo, a directory backend also listDirectory. Unless read-only is set, write is needed as well, and for directories create, remove and rename. A missing callback fails the construction or the start with Bad_InvalidArgument.

Backend handles must be unique within the backend, each with a position of its own. Client handles belong to their Session and close with it.

The callbacks run synchronously with the server lock held and must not block for long. Scans and recursive copies or deletes run in one call, so they take longer for larger trees.

/* Access rights of one Object as a bit mask. For files, read and write give
 * access to the content. For directories, read lists the entries, write
 * changes them and traverse gives access to the children. Every managed
 * ancestor needs traverse. Changing a directory needs write and traverse; a
 * recursive copy needs read and traverse on the directories and read on the
 * files. Traverse has no meaning for files.
 *
 * An operation needs the rights of the storage, of the read-only configuration
 * and of the optional access callbacks together. They apply to the file
 * operations and to Writable/UserWritable; browsing stays with
 * accessControl.allowBrowseNode. Owner, group and ACL checks are up to the
 * backend. */
typedef UA_Byte UA_FileAccessRights;

#define UA_FILEACCESS_TRAVERSE ((UA_FileAccessRights)0x01)
#define UA_FILEACCESS_WRITE    ((UA_FileAccessRights)0x02)
#define UA_FILEACCESS_READ     ((UA_FileAccessRights)0x04)

/* Maximum length of one file name in UTF-8 bytes, without the terminator. It
 * is a limit of the API, not of the filesystem. Never truncate a name. */
#define UA_FILETRANSFER_FILENAME_MAX 1023

typedef struct {
    /* NUL-terminated UTF-8 base name; empty for a directory root */
    char name[UA_FILETRANSFER_FILENAME_MAX + 1];
    UA_UInt64 size;             /* Size in bytes (files only) */
    UA_Boolean sizeUnknown;     /* The Size Property then reports
                                 * Bad_NotSupported (Part 20, 4.2.1) */
    UA_DateTime lastModified;   /* Time of the last change */
    UA_Boolean isDirectory;
    UA_FileAccessRights accessRights; /* Rights of the storage. The access
                                      * callbacks can restrict them further. */
    char mimeType[255];         /* Media type, padded with zeros; it can use all
                                * bytes. Empty adds no MimeType Property and
                                * keeps an existing one. */
} UA_FileTransferFileInfo;

/* Who opens a file. For Open, CreateFile, GenerateFileForRead/-Write, the
 * copies of MoveOrCopy and UA_FileTransferDriver_openHandle(), the driver
 * passes the Session of the Method call. Calls of the application pass
 * NULL. */
typedef struct {
    UA_Server *server;
    const UA_NodeId *sessionId;
    void *sessionContext;
    void *openContext; /* Of UA_FileTransferDriver_openHandle(), else NULL */
} UA_FileTransferOpenContext;

typedef struct UA_FileTransferFileBackend UA_FileTransferFileBackend;
struct UA_FileTransferFileBackend {
    /* State of the backend, e.g. its storage and handles */
    void *context;

    /* Open a file and return a new handle with its own position. mode is a bit
     * mask of UA_OPENFILEMODE_* flags that the driver has validated. Append
     * starts at the end of the file, otherwise the position is zero;
     * EraseExisting empties the file. context is the caller or NULL. For a
     * Method call, the driver has already checked the mode, the locks (Part
     * 20, 4.2.2), the access rights and the handle limits. The result goes
     * back to the client, e.g. Bad_NotSupported for a mode that the file does
     * not offer. */
    UA_StatusCode (*open)(UA_FileTransferFileBackend *b, const UA_String path,
                          UA_Byte mode, const UA_FileTransferOpenContext *context,
                          UA_UInt32 *handle);

    /* Close the handle and flush buffered writes. Report flush errors here; at
     * the target of a copy, such an error fails the copy. */
    UA_StatusCode (*close)(UA_FileTransferFileBackend *b, UA_UInt32 handle);

    /* Read up to length bytes and advance the position. Allocate out; the
     * caller frees it with UA_ByteString_clear(). An empty out marks the end of
     * the file. */
    UA_StatusCode (*read)(UA_FileTransferFileBackend *b, UA_UInt32 handle,
                          UA_Int32 length, UA_ByteString *out);

    /* Write all data and advance the position. The buffer stays with the
     * caller. */
    UA_StatusCode (*write)(UA_FileTransferFileBackend *b, UA_UInt32 handle,
                           const UA_ByteString data);

    /* Get the position of the handle */
    UA_StatusCode (*getPosition)(UA_FileTransferFileBackend *b, UA_UInt32 handle,
                                 UA_UInt64 *outPosition);

    /* Set the position of the handle. A position beyond the end of the file
     * becomes the file size (Part 20, 4.2.7). */
    UA_StatusCode (*setPosition)(UA_FileTransferFileBackend *b, UA_UInt32 handle,
                                 UA_UInt64 position);

    /* Get the metadata, including the base name (empty for a directory root).
     * outInfo is zeroed. Set accessRights explicitly, zero denies access. A
     * name that is too long returns Bad_EncodingLimitsExceeded. */
    UA_StatusCode (*getInfo)(UA_FileTransferFileBackend *b, const UA_String path,
                             UA_FileTransferFileInfo *outInfo);

    /* Optional restriction that does not depend on the client. outRights
     * starts at zero. An error denies access and goes back to the caller. NULL
     * adds no restriction. b->context can hold the policy. */
    UA_StatusCode (*getAccessRights)(UA_FileTransferFileBackend *b,
                                     UA_Server *server, const UA_NodeId *nodeId,
                                     UA_FileAccessRights *outRights);

    /* Optional restriction per Session, with the Session and its context from
     * the Method or Property call. The rules of getAccessRights apply. Open
     * and every Read and Write check the rights again; Close still works after
     * they were revoked. With either access callback, recursive operations
     * reject entries without an Object, because they cannot be checked. */
    UA_StatusCode (*getUserAccessRights)(UA_FileTransferFileBackend *b,
                                         UA_Server *server,
                                         const UA_NodeId *sessionId,
                                         void *sessionContext,
                                         const UA_NodeId *nodeId,
                                         UA_FileAccessRights *outRights);

    /* Release the context when the driver is freed. Optional, called once. */
    void (*clear)(UA_FileTransferFileBackend *b);
};

/* Report one directory entry with complete metadata and a non-empty,
 * NUL-terminated base name.
 *
 * @param listContext Context passed to listDirectory by the caller.
 * @param info Entry metadata, borrowed for this call. Copy it to retain it. */
typedef void
(*UA_FileTransferListCallback)(void *listContext,
                               const UA_FileTransferFileInfo *info);

typedef struct UA_FileTransferBackend UA_FileTransferBackend;
struct UA_FileTransferBackend {
    /* The file operations, first so that b can be cast back to this struct */
    UA_FileTransferFileBackend file;

    /* List the entries at path. Return an error if listing or reading an entry
     * fails, also when an entry disappears meanwhile. An error discards the
     * whole listing, because an incomplete one could lose data during a move.
     * Never truncate names that are too long; return
     * Bad_EncodingLimitsExceeded. */
    UA_StatusCode (*listDirectory)(UA_FileTransferBackend *b, const UA_String path,
                                   UA_FileTransferListCallback cb, void *listContext);

    /* Create an empty entry at path and fail if it exists. info is only valid
     * during the call: name is the base name of path and isDirectory selects
     * the kind. The other fields are zero and ignored; the backend picks the
     * metadata. */
    UA_StatusCode (*create)(UA_FileTransferBackend *b, const UA_String path,
                            const UA_FileTransferFileInfo *info);

    /* Remove a file or an empty directory. The driver removes trees from the
     * bottom up. */
    UA_StatusCode (*remove)(UA_FileTransferBackend *b, const UA_String path);

    /* Move within this backend. Never overwrite or merge an existing target,
     * even one without an Object; return Bad_BrowseNameDuplicated. The driver
     * does not move entries with open handles. */
    UA_StatusCode (*rename)(UA_FileTransferBackend *b, const UA_String fromPath,
                            const UA_String toPath);

    /* Optional copy of a file within this backend; without it, the driver
     * copies with open, read, write and close. Trees are copied entry by
     * entry. As for rename, never overwrite a target or copy an entry with
     * open handles, and remove a partial target on failure. */
    UA_StatusCode (*copy)(UA_FileTransferBackend *b, const UA_String fromPath,
                          const UA_String toPath);
};

Construction and Parameters

Set driver->params before UA_Server_addDriver(). The driver reads them at every start; all keys are in namespace 0. A known key with another type than listed fails the start with Bad_InvalidArgument. Intervals are milliseconds.

0:read-only [Boolean]

Refuse writes and changes to directories (default: false).

0:max-scan-depth [UInt32]

How deep the tree is mirrored; the entries of the root have depth 1, and directories at the limit look empty. 0 means no limit (default). CreateFile, CreateDirectory and MoveOrCopy return Bad_ResourceUnavailable for targets beyond the limit. A lower limit keeps deeper Objects, but no longer refreshes them.

0:max-nodes [UInt32]

Maximum number of mirrored Objects, the root included; 0 means no limit (default). A lower limit does not remove existing Objects.

0:namespace-index [UInt16]

Namespace of the BrowseNames and NodeIds of new entries (default: the namespace of the root Object, 1 for a root in Namespace Zero). Standard Properties and Methods stay in namespace 0.

0:refresh-interval [Double]

How often directories are compared with the backend (default: 1000). 0 turns the periodic refresh off; then call UA_FileTransferDriver_refresh(). A file that disappears while it is open stays until it is closed.

0:max-open-handles-per-session [UInt16]

Open handles per Session in this driver (default: 64).

0:max-open-handles-per-file [UInt16]

Open handles per file (default: 16). When either limit is reached, Open returns Bad_ResourceUnavailable. For temporary drivers, each transfer counts as one handle, and a write transfer always runs alone.

0:activity-timeout [Double]

Close a handle like Close when it sees no Method call for this long, e.g. for the ActivityTimeout of a TrustList (Part 12, 7.8.2.1). The FileType Methods, openHandle and getHandleInfo count as calls. A handle closes at the latest after twice the timeout. 0 turns it off (default). Temporary drivers publish it as ClientProcessingTimeout (default: 60000) and cancel idle transfers.

0:max-transfer-size [UInt64]

Temporary drivers: largest temporary file in bytes (default: 16777216, 0 means no limit). Larger files fail with Bad_ResourceUnavailable.

0:max-read-length [UInt32]

Maximum bytes per Read or Write (default, also for 0: 1048576), published as MaxByteStringLength. Longer reads return this many bytes; longer writes fail with Bad_InvalidArgument.

Each refresh lists every mirrored directory with the server lock held and applies max-nodes in two passes, removals first. For large or deep trees, set max-scan-depth and max-nodes and use a longer refresh-interval, or 0 and UA_FileTransferDriver_refresh(). Skipped entries and trees cut off by the limits are logged at the start and when their numbers change; unchanged results only at debug level.

/* Description of the root Object. Fields left zero select the defaults. The
 * description is only used during the construction. */
typedef struct {
    UA_NodeId nodeId;          /* Existing Object to reuse, or NodeId to create.
                               * Null creates a NodeId in namespace 1. */
    UA_NodeId parentNodeId;    /* Default: Objects folder */
    UA_NodeId referenceTypeId; /* Default: HasComponent */
    UA_QualifiedName browseName; /* Default: base name (file) or 0:FileSystem */
    UA_NodeId typeDefinition;  /* Default: FileType or FileDirectoryType */
    UA_ObjectAttributes attributes; /* Default Object attributes; an empty
                                    * DisplayName uses the BrowseName */
} UA_FileTransferNodeDescription;

/* Construct a stopped driver for an existing file in a backend. The default
 * BrowseName is the base name of path in namespace 1; for the empty path,
 * it is the name from getInfo or "File".
 *
 * An existing description->nodeId reuses that FileType or FileDirectoryType
 * Object (or a subtype); the other fields of the description are ignored.
 * Children are matched by the text of their BrowseName in any namespace.
 * Ambiguous or incompatible entries are rejected; unrelated nodes stay
 * untouched.
 *
 * The bound Objects get the driver as context, also while it is stopped. A
 * reused root is bound at the first start. Freeing the driver removes the
 * nodes it created and restores the contexts of reused Objects and the values,
 * sources and contexts of their Properties. Reused Objects stay when their
 * storage entry disappears, but Delete and successful moves delete them like
 * created ones. Before an Object is deleted, the context from its construction
 * or reuse is restored for the lifecycle destructors of the application.
 *
 * While started, the drivers serve the standard Methods: the shared Method
 * nodes of Namespace Zero and the copies that subtypes inherit. Other Methods
 * of subtypes stay with the application, see
 * UA_FileTransferDriver_getHandleInfo(). The drivers own these Method nodes:
 * the first start replaces callbacks of the application, the last stop
 * removes them. FileType and TemporaryFileTransferType Objects that the
 * application serves without a driver need Method nodes of their own.
 *
 * On success, the backend struct is copied and the driver owns its context. On
 * failure, the created nodes are removed, *outDriver is NULL and the backend
 * stays with the caller. outDriver is required; outNodeId is optional and
 * receives an owned NodeId only on success.
 *
 * Registering is a separate step. Before UA_Server_addDriver() succeeded, the
 * caller frees the driver before deleting the server; afterwards, the server
 * owns it. To free it earlier, stop and remove it first. The start mirrors the
 * directory entries, and the periodic refresh (unless refresh-interval is 0)
 * keeps them up to date. Stop closes the handles but keeps the nodes and the
 * backend for a restart.
 *
 * @param server Server that will own the driver after registration.
 * @param backend File operations and context. Copied on success, when the
 *        driver takes ownership of the context; unchanged on failure.
 * @param path Path of an existing file, relative to the backend root. Copied
 *        by the driver. Use UA_STRING_NULL for a single-file backend.
 * @param description Root Object configuration, or NULL for the defaults.
 *        The description is only used during this call.
 * @param outNodeId Optional output for the root NodeId. Written only on
 *        success; release the returned copy with UA_NodeId_clear().
 * @param outDriver Required output for the stopped driver. Set to NULL on
 *        failure. Register it with UA_Server_addDriver() or free it before
 *        deleting the server.
 * @return UA_STATUSCODE_GOOD on success, or the construction error. */
UA_THREADSAFE UA_StatusCode
UA_FileTransferDriver_newFile(UA_Server *server,
                              const UA_FileTransferFileBackend *backend,
                              const UA_String path,
                              const UA_FileTransferNodeDescription *description,
                              UA_NodeId *outNodeId, UA_Driver **outDriver);

/* Create a stopped driver for the backend's root directory (the empty path).
 * The default BrowseName is 0:FileSystem. Node creation, backend ownership,
 * output parameters and registration follow UA_FileTransferDriver_newFile().
 *
 * @param server Server that will own the driver after registration.
 * @param backend Directory operations and context. Copied on success, when
 *        the driver takes ownership of the context; unchanged on failure.
 * @param description Root Object configuration, or NULL for the defaults.
 *        The description is only used during this call.
 * @param outNodeId Optional output for the root NodeId. Written only on
 *        success; release the returned copy with UA_NodeId_clear().
 * @param outDriver Required output for the stopped driver. Set to NULL on
 *        failure. Register it with UA_Server_addDriver() or free it before
 *        deleting the server.
 * @return UA_STATUSCODE_GOOD on success, or the construction error. */
UA_THREADSAFE UA_StatusCode
UA_FileTransferDriver_newDirectory(UA_Server *server,
                                   const UA_FileTransferBackend *backend,
                                   const UA_FileTransferNodeDescription *description,
                                   UA_NodeId *outNodeId, UA_Driver **outDriver);

/* Synchronize a directory tree with its backend, for example when periodic
 * refresh is disabled.
 *
 * @param driver Started directory driver to refresh.
 * @return UA_STATUSCODE_GOOD on success, Bad_InvalidState for a stopped
 *         driver, Bad_NotSupported for a file or temporary-transfer driver,
 *         or the refresh error. */
UA_THREADSAFE UA_StatusCode
UA_FileTransferDriver_refresh(UA_Driver *driver);

/* Get the open mode and backend handle of a file. Both output pointers may
 * be NULL. fileHandle must belong to the given Session and file Object;
 * otherwise the call returns Bad_InvalidArgument. A successful lookup
 * restarts the activity timeout.
 *
 * Use the backend handle while the server lock is held, for example in a
 * Method callback. Another call or a timeout can close it after this
 * function returns.
 *
 * @param driver Driver that owns the file, including a temporary-transfer
 *        driver for a file returned by generateTemporaryFile().
 * @param fileNodeId NodeId of the FileType Object.
 * @param sessionId Session that owns fileHandle. Must not be NULL.
 * @param fileHandle Handle returned when the file was opened or generated.
 * @param mode Optional output for the UA_OPENFILEMODE_* bit mask. Written
 *        only on success.
 * @param backendHandle Optional output for the backend handle. Written
 *        only on success; its lifetime is limited to the open file.
 * @return UA_STATUSCODE_GOOD on success, or Bad_InvalidArgument if the
 *         arguments or handle do not identify an open file of this Session. */
UA_THREADSAFE UA_StatusCode
UA_FileTransferDriver_getHandleInfo(UA_Driver *driver,
                                    const UA_NodeId fileNodeId,
                                    const UA_NodeId *sessionId,
                                    UA_UInt32 fileHandle, UA_Byte *mode,
                                    UA_UInt32 *backendHandle);

/* Close a file handle like the FileType Close Method and return the backend's
 * close result. The handle is released even if the backend reports an error.
 * fileHandle must belong to the given Session and file Object; otherwise the
 * call returns Bad_InvalidArgument. Closing a temporary file ends its
 * transfer without committing a write. Can be called from Method callbacks.
 *
 * @param driver Driver that owns the file, including temporary files.
 * @param fileNodeId NodeId of the FileType Object.
 * @param sessionId Session that owns fileHandle. Must not be NULL.
 * @param fileHandle Handle to close. Invalidated by this call.
 * @return The backend's close StatusCode, or Bad_InvalidArgument if the
 *         arguments or handle do not identify an open file of this Session. */
UA_THREADSAFE UA_StatusCode
UA_FileTransferDriver_closeHandle(UA_Driver *driver,
                                  const UA_NodeId fileNodeId,
                                  const UA_NodeId *sessionId,
                                  UA_UInt32 fileHandle);

/* Subtype Methods that open the file with their own arguments, e.g.
 * OpenWithMasks of a TrustList (Part 12), create the FileHandle with
 * openHandle; openContext reaches the backend open, e.g. with the masks.
 * Methods that take file NodeIds as arguments, e.g. ValidateFiles of DI (OPC
 * 10000-100), open the files the same way and read them through the backend.
 * The checks and results of the Open Method apply; a stopped driver returns
 * Bad_InvalidState and a node that is not a file of the driver
 * Bad_InvalidArgument. The handle belongs to the Session like one from Open:
 * it counts in OpenCount and the handle limits and closes with the Session.
 * Return fileHandle to the client, or close it with closeHandle if the Method
 * fails afterwards. backendHandle is optional; use it with the server lock
 * held, as described for UA_FileTransferDriver_getHandleInfo().
 *
 * @param driver Started file or directory driver that owns the file.
 * @param fileNodeId NodeId of an existing, non-temporary FileType Object.
 * @param sessionId Session that will own the handle. Must not be NULL.
 * @param sessionContext Session context forwarded to the backend, or NULL.
 * @param mode Bit mask of UA_OPENFILEMODE_* flags, as for the Open Method.
 * @param openContext Application data passed to backend open, or NULL. It is
 *        borrowed for that call; the application retains ownership.
 * @param fileHandle Required output for the Session's handle. Written only
 *        on success. Close it with UA_FileTransferDriver_closeHandle().
 * @param backendHandle Optional output for the backend handle. Written only
 *        on success; its lifetime is limited to the open file.
 * @return UA_STATUSCODE_GOOD on success, Bad_InvalidState for a stopped
 *         driver, Bad_InvalidArgument for a node outside the driver's storage
 *         or a temporary file, or the Open error. */
UA_THREADSAFE UA_StatusCode
UA_FileTransferDriver_openHandle(UA_Driver *driver,
                                 const UA_NodeId fileNodeId,
                                 const UA_NodeId *sessionId,
                                 void *sessionContext, UA_Byte mode,
                                 void *openContext, UA_UInt32 *fileHandle,
                                 UA_UInt32 *backendHandle);

Local Backends

These constructors create independent backend contexts and can be called from separate threads with separate outputs. Once a backend belongs to a driver, direct calls to its operations require the server lock.

/* Serve an existing local directory; rootPath is UTF-8 and copied. out is only
 * written on success. The rights follow the filesystem permissions of the
 * server process, limited further by the optional access callbacks. On
 * Windows, the filesystem operations check the traversal.
 *
 * Paths with ".." segments are rejected, but links to regular files are
 * followed, also outside rootPath: this is no sandbox, not even with
 * read-only. Links to directories and special files are skipped; directories
 * that contain them cannot be deleted through the driver (Bad_InvalidState).
 * Windows rejects names it cannot represent. On 32-bit POSIX, positions are
 * limited to 2 GiB.
 *
 * @param rootPath UTF-8 path of an existing local directory. Copied on success.
 * @param out Required output for the backend. Written only on success. The
 *        caller owns its context until a driver takes ownership; otherwise
 *        release it with out->file.clear(&out->file).
 * @return UA_STATUSCODE_GOOD on success, Bad_NotSupported on platforms
 *         without a local backend, or the initialization error. */
UA_THREADSAFE UA_StatusCode
UA_FileTransferBackend_localDirectory(const UA_String rootPath,
                                      UA_FileTransferBackend *out);

/* Serve one existing regular file with the same local I/O and permissions.
 * filePath is UTF-8 and copied; out is only written on success. Links to
 * regular files are followed. Only the empty backend path is accepted; getInfo
 * reports the base name and the media type. Pass UA_STRING_NULL as path to
 * newFile().
 *
 * @param filePath UTF-8 path of an existing regular file. Copied on success.
 * @param out Required output for the backend. Written only on success. The
 *        caller owns its context until a driver takes ownership; otherwise
 *        release it with out->clear(out).
 * @return UA_STATUSCODE_GOOD on success, Bad_NotSupported on platforms
 *         without a local backend, or the initialization error. */
UA_THREADSAFE UA_StatusCode
UA_FileTransferFileBackend_localFile(const UA_String filePath,
                                     UA_FileTransferFileBackend *out);

Temporary File Transfer

A TemporaryFileTransferType Object (Part 20, 4.4) creates a file for one transfer. For GenerateFileForRead, the application fills the file and the client reads it. For GenerateFileForWrite, the client writes the file and CloseAndCommit hands it to the application; Close cancels. Only the Session that generated a file can use it.

The driver cannot know the content, so the application provides and takes it in callbacks. They run with the server lock held and must not stop or remove the driver. The content helpers below rely on this lock and must run synchronously in these callbacks, on the calling thread.

Use the access control plugin to authorize GenerateFileForRead and GenerateFileForWrite. Backend access callbacks receive the random NodeId of each temporary file.

  • generateFileForRead fills the new file.

  • generateFileForWrite can refuse a write, e.g. for unknown generateOptions.

  • closeAndCommit takes the written file and returns the result of CloseAndCommit. The driver removes the file afterwards, so copy or move what you keep.

  • endTransfer runs once when a transfer ends, also when its creation fails after a successful generate callback; free transferContext there. The status says how the transfer ended, e.g. Good, the result of closeAndCommit, Bad_RequestCancelledByClient, Bad_Timeout or Bad_SessionClosed.

See examples/filetransfer/server_filetransfer_temporary.c.

/* The temporary file of one transfer, only valid during the callback */
typedef struct {
    const UA_NodeId *sessionId;
    void *sessionContext;              /* NULL in endTransfer */
    const UA_Variant *generateOptions; /* Can be an empty Variant */
    UA_FileTransferBackend *store;     /* Of the driver, do not clear */
    UA_String path;                    /* Of the file in the store */
    UA_Boolean forWrite;
    void *transferContext;             /* Of the application, initially NULL */
} UA_FileTransferTemporaryFile;

/* Prepare or commit a temporary file while the server lock is held.
 *
 * @param server Server executing the transfer callback.
 * @param context Application context from UA_FileTransferTemporaryOptions.
 * @param file Temporary file and transfer state, borrowed for this callback.
 *        The callback may update file->transferContext.
 * @return UA_STATUSCODE_GOOD to accept the operation, or an error to reject
 *         it. A failed generate callback must release any context it created. */
typedef UA_StatusCode
(*UA_FileTransferTemporaryCallback)(UA_Server *server, void *context,
                                    UA_FileTransferTemporaryFile *file);

/* Handle transfer completion while the server lock is held.
 *
 * @param server Server executing the completion callback.
 * @param context Application context from UA_FileTransferTemporaryOptions.
 * @param file Temporary file and transfer state, borrowed for this callback.
 *        file->sessionContext is NULL. Release application-owned transfer
 *        state here; the driver removes the temporary file afterwards.
 * @param status Final status of the transfer, including cancellation or
 *        failure after a successful generate callback. */
typedef void
(*UA_FileTransferTemporaryEndCallback)(UA_Server *server, void *context,
                                       UA_FileTransferTemporaryFile *file,
                                       UA_StatusCode status);

/* Replace the contents of a temporary file. The caller keeps ownership of
 * content. Call only from a temporary-transfer callback with the server
 * lock held; this helper does not acquire the lock itself.
 *
 * @param file Temporary file supplied to the current callback.
 * @param content Bytes to write. Borrowed for this call; an empty ByteString
 *        clears the file.
 * @return UA_STATUSCODE_GOOD on success, Bad_InvalidArgument for a NULL file,
 *         or the backend I/O error. */
UA_StatusCode
UA_FileTransferTemporaryFile_setContent(UA_FileTransferTemporaryFile *file,
                                        const UA_ByteString content);

/* Read a copy of the temporary file into content. The caller must release
 * the result with UA_ByteString_clear(). Call only from a temporary-transfer
 * callback with the server lock held; this helper does not acquire the lock.
 *
 * @param file Temporary file supplied to the current callback.
 * @param content Required output for the allocated content. Must not already
 *        own a buffer. Initialized by this call and cleared on I/O failure.
 * @return UA_STATUSCODE_GOOD on success, Bad_InvalidArgument for a NULL file
 *         or output pointer, or the backend I/O or allocation error. */
UA_StatusCode
UA_FileTransferTemporaryFile_getContent(UA_FileTransferTemporaryFile *file,

typedef struct {
    UA_FileTransferTemporaryCallback generateFileForRead;  /* NULL: Bad_NotReadable */
    UA_FileTransferTemporaryCallback generateFileForWrite; /* Optional */
    UA_FileTransferTemporaryCallback closeAndCommit;       /* NULL: Bad_NotWritable */
    UA_FileTransferTemporaryEndCallback endTransfer;       /* Optional */
    void *context;                                         /* Passed to the callbacks */
    /* Storage for temporary files. Leave zero-initialized to use memory.
     * A custom backend must provide the file operations, create and remove. */
    UA_FileTransferBackend store;
} UA_FileTransferTemporaryOptions;

/* Create a stopped driver for a TemporaryFileTransferType Object. Provide
 * generateFileForRead, closeAndCommit, or both.
 *
 * The driver takes ownership of options->store and resets it to zero. If
 * creation fails, the backend is cleared before returning. Node creation,
 * output parameters and registration follow UA_FileTransferDriver_newFile(),
 * with the default BrowseName 1:TemporaryFileTransfer.
 *
 * read-only disables GenerateFileForWrite. max-scan-depth, max-nodes and
 * refresh-interval are ignored.
 *
 * @param server Server that will own the driver after registration.
 * @param options Required callbacks, context and storage configuration. The
 *        store is consumed and zeroed even on failure; other fields are
 *        copied. The application retains ownership of options->context.
 * @param description TemporaryFileTransferType Object configuration, or NULL
 *        for the defaults. An existing Object of this type or a subtype can
 *        be reused. The description is only used during this call.
 * @param outNodeId Optional output for the root NodeId. Written only on
 *        success; release the returned copy with UA_NodeId_clear().
 * @param outDriver Required output for the stopped driver. Set to NULL on
 *        failure. Register it with UA_Server_addDriver() or free it before
 *        deleting the server.
 * @return UA_STATUSCODE_GOOD on success, or the construction error. */

UA_FileTransferDriver_newTemporary(UA_Server *server,

                                   const UA_FileTransferNodeDescription *description,
                                   UA_NodeId *outNodeId, UA_Driver **outDriver);

/* Get an active temporary transfer's direction and application context.

 * @param driver Temporary-transfer driver that owns the transfer.

 * @param fileHandle Handle returned when the temporary file was generated.
 * @param forWrite Optional output, true for a write transfer and false for a
 *        read transfer. Written only on success.
 * @param transferContext Optional output for the application's current
 *        transfer context, which may be NULL. Written only on success.
 * @return UA_STATUSCODE_GOOD on success, Bad_NotSupported for a file or
 *         directory driver, or Bad_InvalidArgument for invalid arguments or
 *         a handle that does not belong to this Session. */

                                               void **transferContext);

Supported Security Policies

A SecurityPolicy is a named bundle of algorithms for asymmetric signing, asymmetric encryption, symmetric encryption, key derivation, and message signing. OPC UA Part 7 defines the standard SecurityPolicies as Profiles in the online Profile database at https://profiles.opcfoundation.org. A server advertises its supported policies through its Endpoints (returned by GetEndpoints). The client picks one when opening a SecureChannel.

The tables below list every SecurityPolicy of the UACore 1.05 Profile group and show which crypto backend implements it. Adding a policy to a server is the same call regardless of backend – UA_ServerConfig_addSecurityPolicy*() (see ECC Specifics for the full call list).

Status and required policies

  • Current: the Profile is released and not deprecated.

  • Deprecated: the Profile database marks the Profile as deprecated. Do not use it for new systems.

The conformance unit Security Policy Required asks every application that supports security for at least SecurityPolicy [A] (Aes128_Sha256_RsaOaep) and SecurityPolicy [B] (Basic256Sha256). The conformance unit Security ECC Policy asks for one of SecurityPolicy [ECC A] or [ECC B]. The Profile database gives the label [ECC A] to ECC_nistP256_AesGcm and ECC_brainpoolP256r1_AesGcm, and the label [ECC B] to ECC_curve25519_ChaChaPoly. Both conformance units also say that obsolete SecurityPolicies shall not be enabled or usable without administrative intervention.

Security level

Each UA_SecurityPolicy has a securityLevel that gives an estimate of the strength of the security policy in relation to other security policies. The default server configuration populates the security level of the endpoint descriptions from the security level of the underlying security policy. Clients usually prefer endpoints with the highest security level.

A security level of 0 is for None and for all deprecated policies. UA_ServerConfig_addAllSecureEndpoints creates no Endpoints for policies with level 0. PubSub SecurityPolicies have no security level.

Not implemented

open62541 does not implement these SecurityPolicies of the UACore 1.05 Profile group.
